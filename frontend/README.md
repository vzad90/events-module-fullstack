# Events Frontend

---

## Tech stack

- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **HTTP**: native `fetch`, small API helper
- **Forms**: React state (`useState`), no external form libraries

---

## Getting started

### 1. Install dependencies

From the `frontend` directory:

```bash
npm install
```

2. Environment variables

Create .env.local

3. Run the dev server:

````bash
npm run dev
````
